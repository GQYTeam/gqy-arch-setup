# Arch Linux 安装

## GQYOS 安装流程

1. 从 ISO 启动 → `sudo gqyos-install`
2. 自动分区：UEFI → GRUB → LUKS2 加密 → LVM
3. pacstrap 安装基础系统
4. 配置 bootloader、网络、用户
5. 重启 → 运行 `install.sh` 部署桌面

## 手动安装参考

```bash
# 分区 (UEFI)
gdisk /dev/nvme0n1
# 1: 512M EFI (EF00)
# 2: 剩余空间 Linux LVM (8E00)

# 加密
cryptsetup luksFormat /dev/nvme0n2
cryptsetup open /dev/nvme0n2 cryptlvm

# LVM
pvcreate /dev/mapper/cryptlvm
vgcreate vg0 /dev/mapper/cryptlvm
lvcreate -L 16G vg0 -n swap
lvcreate -l 100%FREE vg0 -n root

# 格式化
mkfs.fat -F32 /dev/nvme0n1p1
mkfs.ext4 /dev/vg0/root

# 挂载
mount /dev/vg0/root /mnt
mkdir /mnt/boot
mount /dev/nvme0n1p1 /mnt/boot

# 安装
pacstrap /mnt base linux linux-firmware
genfstab -U /mnt >> /mnt/etc/fstab
arch-chroot /mnt
```

## 常见问题

| 问题 | 解决 |
|------|------|
| boot 无法启动 | 检查 ESP 挂载和 GRUB 配置 |
| LUKS 密码错误 | 确认 `cryptsetup open` 正确 |
| 网络不通 | `systemctl enable --now NetworkManager` |
| 时区错误 | `timedatectl set-timezone Asia/Shanghai` |

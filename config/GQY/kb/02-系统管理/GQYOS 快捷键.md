# GQYOS 快捷键

## Hyprland 全局

| 快捷键 | 功能 |
|--------|------|
| `Super + Enter` | 打开终端 (Kitty) |
| `Super + Q` | 关闭窗口 |
| `Super + M` | 退出 Hyprland |
| `Super + V` | 切换浮动 |
| `Super + J` | 切换窗口布局 |
| `Super + 1-9` | 切换工作区 |
| `Super + Shift + 1-9` | 移动窗口到工作区 |
| `Super + 方向键` | 切换焦点 |
| `Super + 鼠标拖动` | 移动窗口 |
| `Super + P` | dumbjump |

## 应用启动

| 快捷键 | 功能 |
|--------|------|
| `Super + D` | Fuzzel 启动器 |
| `Super + E` | Yazi 文件管理器 |
| `Super + T` | Kitty 终端 |
| `Super + B` | 浏览器 |

## Tmux (Ctrl+a 前缀)

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+a + c` | 新建窗口 |
| `Ctrl+a + n/p` | 下/上一个窗口 |
| `Ctrl+a + 方向键` | 切换面板 |
| `Ctrl+a + d` | 断开会话 |
| `Ctrl+a + r` | 恢复会话 |

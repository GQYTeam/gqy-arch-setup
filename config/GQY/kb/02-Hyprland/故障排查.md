# Hyprland 故障排查

## 常见问题

### 黑屏

```bash
# 检查 Wayland 是否启动
echo $XDG_SESSION_TYPE  # 应为 wayland

# 检查 Hyprland 日志
journalctl -b | grep -i hypr

# 检查显卡驱动
lspci | grep -i vga
```

### 无法启动

```bash
# 从 TTY 启动
hyprctl kill
Hyprland

# 检查配置语法
hyprctl getoption general:monitor
```

### 性能问题

```bash
# 查看帧率
hyprctl hyprpaper wallpaper

# 检查渲染器
hyprctl systeminfo | grep renderer
```

### 输入设备不工作

```bash
# 查看输入设备
hyprctl devices

# 测试输入
wev  # Wayland 输入事件查看器
```

### 屏幕共享

```bash
# 确保 xdg-desktop-portal 已安装
sudo pacman -S xdg-desktop-portal-hyprland

# 检查
systemctl --user status xdg-desktop-portal
```

## 调试命令

```bash
# 查看所有信息
hyprctl systeminfo

# 实时监控
hyprctl monitor all

# 查看动画状态
hyprctl getoption animations:enabled
```

# Hyprland 插件

## 已安装插件

GQYOS 默认安装：

| 插件 | 功能 |
|------|------|
| hyprlock | 锁屏 |
| hypridle | 电源管理 |
| hyprpaper | 壁纸 |

## 插件管理

```bash
# 查看已加载插件
hyprctl plugins list

# 手动加载
hyprctl plugin load /path/to/plugin.so

# 卸载
hyprctl plugin unload plugin_name
```

## hyprlock

```bash
# 手动锁屏
hyprlock

# 配置: ~/.config/hyprlock/hyprlock.conf
```

## hypridle

```bash
# 配置: ~/.config/hypridle/hypridle.conf

# 超时动作:
# 亮度降低 → 锁屏 → DPMS off → 休眠
```

## hyprpaper

```bash
# 配置: ~/.config/hyprpaper/hyprpaper.conf

# 壁纸设置
hyprctl hyprpaper wallpaper "DP-1,~/wallpaper.png"
```

## 第三方插件

```bash
# 安装 hyprland-plugins (AUR)
yay -S hyprland-plugins

# 常用插件:
# - hyprscroller: 类似 bspwm 的滚动布局
# - hyprtask: 任务管理
```
